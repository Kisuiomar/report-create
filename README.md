# 🕵️‍♂️ Offline Dossier & Entity Extraction Engine

Автономная система для глубокого анализа документов, извлечения сущностей и формирования досье. Работает **на 100% локально** (Air-Gapped) с использованием архитектуры RAG (Retrieval-Augmented Generation).

## 🚀 Системные требования

Проект изначально оптимизирован под работу на промышленных ИИ-серверах:
- **ОС:** Linux (Ubuntu/Debian) — основная целевая платформа.
- **ОЗУ (RAM):** 128+ ГБ.
- **Видеокарта (GPU):** Промышленный кластер (аналог NVIDIA RTX Spark) с **1 ТБ видеопамяти (VRAM)**.
- **Диск:** SSD/NVMe (1 ТБ+) для хранения гигантских баз знаний Qdrant и моделей.

## 📦 Предварительная установка (Только один раз)

1. **Скачайте и установите Docker:**
   - **Для Windows:** Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/). При установке обязательно включите галочку **"Use WSL 2 based engine"**.
   - **Для Linux:** Установите Docker Engine и [NVIDIA Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/install-guide.html).
2. Убедитесь, что у вас установлены свежие драйверы видеокарты NVIDIA.

## 🛠 Запуск системы

### Для пользователей Windows
1. Скачайте эту папку с проектом к себе на компьютер.
2. Дважды кликните по файлу **`Запуск_Сервера.bat`**.
3. При первом запуске система скачает образы и тяжелые нейросети (Qwen 27B и Nomic-Embed). Это скачает около 16-20 ГБ данных, поэтому **наберитесь терпения**, процесс может занять от 15 минут до часа в зависимости от интернета.
4. По завершении скрипт автоматически откроет браузер по адресу `http://localhost`.

### Для пользователей Linux
1. Склонируйте репозиторий или скачайте архив с кодом.
2. Откройте терминал в папке с проектом и выполните:
   ```bash
   chmod +x start.sh
   ./start.sh
   ```
3. Дождитесь скачивания моделей.
4. Откройте браузер и перейдите по адресу `http://localhost`.

## 🧠 Как работает RAG-архитектура

Система не ограничена размером документов (можно загружать архивы на тысячи страниц):
1. Вы загружаете документ.
2. Текст автоматически извлекается, очищается и нарезается на смысловые фрагменты, которые сохраняются в векторную базу **Qdrant**.
3. Большая нейросеть делает точечные запросы к базе данных для поиска конкретных фактов (связи, родственники, работа, адреса).
4. Нейросеть агрегирует данные и выдает готовое подробное досье в формате JSON и Markdown.

## 🛑 Остановка сервера
Если вы хотите выключить сервер и освободить память видеокарты, откройте командную строку в папке с проектом и введите:
```bash
docker-compose down
```
Все ваши проанализированные документы **сохранятся** в папке `qdrant_data`, и при следующем запуске система их "вспомнит".
