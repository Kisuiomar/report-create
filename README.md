# 100% Offline Dossier & Entity Extraction Pipeline

Модульная автономная (100% offline, air-gapped) система на Python для автоматического извлечения досье, сущностей и родственных связей из разнородных документов (PDF, DOCX, XLSX, HTML, JSON, TXT, сканы JPG/PNG) с последующей выгрузкой структурированных отчетов в форматах **PDF, DOCX, XLSX, JSON** с использованием локальной LLM (**Ollama** / **vLLM** с моделью **Qwen3.8-27B-Uncensored 262k**).

---

## Ключевые возможности

1. **100% Air-Gapped / Offline**:
   - Никаких внешних облачных API. Все вычисления, парсинг, OCR и LLM-инференс выполняются строго локально в изолированном контуре.
2. **Универсальный парсинг любых форматов**:
   - **PDF**: умное разделение страниц. Если на странице есть цифровой текстовый слой (>50 символов) — извлекается нативный текст. Если страница является сканом — автоматически запускается OCR.
   - **DOCX (Word)**: извлечение параграфов, иерархии заголовков и конвертация таблиц Word в компактный Markdown.
   - **XLSX (Excel)**: считывание всех листов с сохранением колонок и структурированием в Markdown-таблицы.
   - **HTML**: удаление скриптов, стилей, рекламных баннеров и навигации, извлечение чистого смыслового дерева.
   - **JSON / TXT**: очистка от служебных envelopes, форматирование в плоский читаемый текст.
   - **Сканы и изображения (JPG/PNG/TIFF/BMP)**: предварительная обработка (grayscale, автоконтраст) и офлайн-распознавание через RapidOCR (ONNX) / Tesseract.
3. **Очистка и экономия контекстного окна (`cleaner.py`)**:
   - Дедупликация повторяющихся фрагментов и колонтитулов.
   - Сжатие мусорных разделителей и пустых строк.
   - Точная оценка токенов под контекст Qwen3.8-27B-Uncensored (262k токенов).
4. **Гарантия 100% валидного JSON (`llm_client.py`)**:
   - Передача строгой схемы JSON Schema (`DossierReport.model_json_schema()`) в Ollama / vLLM.
   - Многоуровневый Fallback: регулярные выражения, удаление висячих запятых, автобалансировка незакрытых скобок `{}` и `[]` при обрыве генерации.
5. **Мультиформатный экспорт (`exporters/`)**:
   - **DOCX**: фирменное оформление, карточка субъекта, плашка резюме и стилизованные таблицы связей.
   - **XLSX**: 4 структурированные вкладки («Анкета», «Контакты и адреса», «Родственные связи», «Места работы») с цветовой подсветкой совпадений.
   - **PDF**: аккуратная табличная верстка с поддержкой шрифтов UTF-8 (русский и казахский алфавит: Ә, І, Ң, Ғ, Ү, Ұ, Қ, Ө, һ).
   - **JSON**: полный валидированный объект Pydantic.
6. **Современный веб-интерфейс (Octopus UI)**:
   - Стеклянный неоморфизм / glassmorphism, темная тема, плавные микроанимации.
   - Мультиязычность: мгновенное переключение языков (Русский, Қазақша, English).
   - Интерактивный предпросмотр связей, подсветка общих признаков и скачивание файлов в 1 клик.

## Архитектура проекта

```text
offline_dossier_pipeline/
├── app/
│   ├── config.py             # Настройки путей, URL Ollama/vLLM, num_ctx=131072, temp=0.1

│   │   ├── base.py           # Базовый интерфейс BaseParser и ParsedDocument

│   │   └── ocr_parser.py     # RapidOCR (ONNX) / Tesseract оффлайн OCR
│   ├── core/
│   │   ├── cleaner.py        # Дедупликация, чистка разметки, компрессия для токенов
│   │   ├── llm_client.py     # Коннектор к локальной LLM с JSON Schema и regex-fallback
│   │   └── schemas.py        # Pydantic v2 модели (ContactInfo, Address, Employment, RelativeRelation, DossierReport)
│   ├── exporters/            # Генерация отчетов
│   │   ├── export_json.py    # Экспорт в JSON
│   │   ├── export_docx.py    # Экспорт в DOCX (Word)
│   │   ├── export_xlsx.py    # Экспорт в Excel (4 вкладки)
│   │   └── export_pdf.py     # Экспорт в PDF (UTF-8, кириллица + казахский)
│   ├── static/               # Веб-интерфейс в стиле Octopus (glassmorphism, RU/EN/KZ)
│   │   ├── index.html
│   │   ├── style.css
│   │   └── app.js
│   └── pipeline.py           # Главный контроллер workflow (оркестратор)
├── data/
│   ├── uploads/              # Временная папка загрузок
│   └── outputs/              # Готовые сгенерированные отчеты
├── requirements.txt
├── main.py                   # Точка входа (Typer CLI + FastAPI)
└── README.md
```

## Быстрый старт

### 1. Подготовка окружения Python

```bash
# Создание виртуального окружения
python -m venv .venv

# Активация (Windows PowerShell)
.venv\Scripts\Activate.ps1

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Запуск локальной LLM

#### Вариант А: Ollama (рекомендуется)
```bash
# Установка и запуск модели Qwen3.8-27B-Uncensored с поддержкой контекста 262k
ollama run orcarouter/Qwen3.8-27B-Uncensored
```

#### Вариант Б: vLLM
```bash
vllm serve orcarouter/Qwen3.8-27B-Uncensored --max-model-len 262144 --port 8000
```

Проверить подключение к локальной LLM:
```bash
python main.py check-llm
```

## Использование через CLI

### Извлечение досье из файлов:
```bash
# Обработка одного или нескольких документов с экспортом во все форматы:
python main.py extract doc1.pdf doc2.docx scanned_passport.png

# Указание конкретных форматов и целевой папки:
python main.py extract report.xlsx --export pdf,docx,xlsx --out ./my_reports
```

### Запуск Веб-сервера и интерфейса:
```bash
python main.py serve --host 0.0.0.0 --port 8000
```
После запуска откройте браузер: `http://localhost:8000`.

## API Эндпоинты FastAPI

- `GET /` — Веб-интерфейс Octopus UI (drag & drop, предпросмотр, мультиязычность).
- `GET /api/health` — статус локальной модели LLM и системы.
- `POST /api/process` — загрузка документов (`multipart/form-data`) и запуск пайплайна:
  - Возвращает полный объект `DossierReport` JSON и пути к файлам отчетов.
- `GET /api/download/{filename}` — скачивание сгенерированного файла отчета.

## Схемы данных (Pydantic v2)

- **`ContactInfo`**: номера телефонов, email, профили в мессенджерах и соцсетях.
- **`Address`**: тип (прописка, фактический, прежний), город, область, полный адрес.
- **`Employment`**: наименование организации, БИН/ИНН, должность, период работы, примечания.
- **`RelativeRelation`**: ФИО родственника, степень связи, ИИН (при наличии), общие признаки связи (`shared_attributes`: общий адрес, телефон, активы), заметки.
- **`SubjectProfile`**: ФИО основного лица, ИИН, дата рождения, место рождения, гражданство, пол.
- **`DossierReport`**: итоговый отчет, включающий профиль субъекта, контакты, адреса, историю занятости, карту родственных связей и сводные выводы аналитика (`executive_summary`).
